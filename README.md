# TMN
This repository contains fMRI processing scripts for an experiment focused on tactile stimulus discrimination. Participants evaluated right hand tactile stimulations and made corresponding left hand selections across Memory and No memory conditions. The provided code covers the full analytical pipeline from raw DICOM conversion to group level linear mixed effects modeling using AFNI.

Preprocessing Code
s1.convert_DICOM.zsh
This script performs the initial data preparation by running the dcm2niix_afni program to convert raw DICOM scan files into NIfTI format. It automatically organizes T1 structural anatomy images and functional MRI task data for both memory and non memory runs. It also processes reverse phase encoding scans which are necessary for subsequent EPI distortion correction. The script requires a subject ID provided as a command line argument to execute.

s2_i.create_proc_M.zsh
This script generates the single subject preprocessing and regression analysis pipeline for the memory task using the afni_proc.py program. It assembles the task runs and applies EPI distortion correction using the forward and reverse phase encoding scans. The command includes options for nonlinear spatial registration to the MNI152 2009 template space and spatial smoothing of 4.0 mm. By default, the execution command is commented out so users can safely review the generated pipeline before running it.

M.proc.TMN01
This is the main execution script automatically generated by the previous step. It runs the full preprocessing and noise regression steps for a single subject. The workflow includes signal uniformity correction, B0 magnetic field distortion correction, and temporal preprocessing. It calculates head motion parameters and censors data volumes with high motion or excessive outliers. Notably, it projects out basic motion noise without task stimulus modeling to create pure residual time series data for subsequent hierarchical modeling. Upon completion, it automatically generates a Pythonic HTML quality control web page.

LME Analysis Code
lme_freq_1.sh
This script performs a group level linear mixed effects analysis using the 3dLMEr program. It models frequency as a quantitative variable to investigate its continuous effect on the brain. The statistical model specification incorporates random intercepts for each subject and for the interaction between subject and run to account for repeated measures. The script also configures a general linear test to explicitly evaluate the overall frequency effect. A predefined group mask restricts the analysis to valid brain regions, and the input data structure is supplied via the accompanying text file.

lme_freq_2.sh
This script executes a parallel group level linear mixed effects analysis. It maintains the identical statistical model specification as the initial LME script, retaining the continuous frequency variable alongside random intercepts for both subjects and runs. The primary distinction is the utilization of a secondary input data structure. This setup allows for a comparative evaluation or an extension of the frequency effect analysis across a modified data configuration.

Data Tables
newDataTable_fin_SK.txt and newDataTable_fin_SK_2.txt
These text files serve as the structural backbone for the linear mixed effects analysis. They organize the input data by explicitly mapping each subject, run, and frequency level to its corresponding beta image file. The first file contains the primary dataset configurations across multiple subjects and their respective functional runs for eleven distinct frequency conditions ranging from 10 to 20. The second file follows an identical tabular format, providing an alternative data configuration for parallel statistical evaluation.
